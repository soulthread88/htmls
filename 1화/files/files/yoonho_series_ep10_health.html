📱 삼성 헬스 시작하기

1️⃣ 삼성 헬스 설치 (삼성 폰)
이미 깔려 있어요!

1. 앱 목록에서 "삼성 헬스" 찾기
(하트 모양 아이콘)

2. 없으면 플레이 스토어에서
"Samsung Health" 검색해서 설치

3. 첫 실행 시 권한 허용
→ 신체 활동 인식
→ 위치 정보 (산책 기록용)

4. 기본 정보 입력
→ 성별, 나이, 키, 몸무게
→ 건강 목표 설정
2️⃣ 아이폰 건강 앱 (아이폰)
기본 앱이에요!

1. 하얀 하트 아이콘 "건강" 앱 열기

2. "시작하기" 버튼 터치

3. 기본 정보 입력
→ 생년월일, 성별, 키, 몸무게

4. 걸음 수 자동 추적 시작!
(iPhone 들고 다니기만 하면 돼요)

🎯 목표 설정하기

💪 나만의 건강 목표
무리하지 않게!

추천 걸음 수 목표:
• 60대: 하루 7,000~8,000보
• 70대: 하루 5,000~7,000보
• 80대: 하루 3,000~5,000보

목표 설정 방법:
1. 삼성 헬스에서 걸음 수 탭 터치
2. 오른쪽 위 설정 버튼
3. "하루 목표" 변경
4. 원하는 걸음 수 입력!

처음엔 낮게 시작해서
천천히 늘려가세요!

→ 시간대별 활동 확인

4. 주간/월간 리포트
→ 건강 트렌드 파악
→ 꾸준히 기록하면 동기부여!
