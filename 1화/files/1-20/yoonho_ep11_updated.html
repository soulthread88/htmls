👨‍🍳 AI 요리 도우미 사용하기

1️⃣ AI에게 레시피 물어보기

이렇게 질문하세요:

✓ 재료로 검색
"감자와 당근으로 만들 수 있는 요리 알려줘"

✓ 시간 고려
"30분 안에 만들 수 있는 저녁 메뉴"

✓ 인원수 포함
"4인 가족용 저녁 레시피"

✓ 건강 고려
"당뇨병 환자를 위한 저염식"

엄마가 AI에게 냉장고 재료로 요리법을 물어보는 장면
"AI가 감자와 당근으로 만드는 레시피를 알려줘요!"

2️⃣ 재료 대체 제안 받기

재료가 없을 때:

✓ "우유 대신 뭘 쓸 수 있어?"
→ AI가 두유, 아몬드밀크 등 제안

✓ "설탕 없이 단맛 내는 방법?"
→ 꿀, 스테비아 등 대안 제시

✓ "계란 알레르기인데 대체재는?"
→ 두부, 바나나 등 설명

✓ "양념이 없어요"
→ 집에 있는 재료로 만드는 법

👩 엄마:

"오! 이렇게 간편하게 레시피를 찾을 수 있구나! 정말 좋다!"

AI가 재료 대체 방법을 제안하는 화면
"없는 재료는 대체 재료로 바꿔요!"

3️⃣ 요리 중 실시간 도움

이런 질문도 가능해요:

✓ "불 세기는 어떻게?"
→ "중불로 5분" 등 구체적 답변

✓ "언제까지 삶아?"
→ 정확한 시간 알려줌

✓ "간이 싱거워요"
→ 조절 방법 안내

✓ "이 재료 먹어도 되나요?"
→ 유통기한, 보관법 설명

👦 윤호 선생님:

"엄마, 요리하면서 궁금한 거 있으면 바로바로 물어보세요! AI가 실시간으로 도와줘요!"
