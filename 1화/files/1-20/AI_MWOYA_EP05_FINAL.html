📱 할머니의 고민

어느 날, 할머니께서 김치찌개를 만들려고 네이버에서 레시피를 검색했어요.

그런데 너무 많은 결과가 나와서 어떤 것을 봐야 할지 모르겠다고 하셨어요.

할머니가 스마트폰으로 검색하는 장면
"검색 결과가 너무 많아요!"
👵 할머니:

"윤호야, 할머니가 네이버에서 김치찌개 레시피 검색했는데 너무 많이 나와서 뭘 봐야 할지 모르겠어..."

👦 윤호 선생님:

"할머니! 검색하는 방법을 알려드릴게요! 쉬운 방법이 있어요!"

👴 할아버지:

"나도 궁금하다! 병원 찾는 건 어떻게 해?"

🎯 윤호가 알려주는 검색의 3가지 비밀

네이버 검색창 화면
"검색의 비밀을 알려드려요!"

1️⃣ 짧고 명확하게!

나쁜 예: "김치찌개를 맛있게 끓이려면 어떻게 해야 하나요?"

좋은 예: "김치찌개 레시피"

➡️ 핵심만 검색하세요!

2️⃣ 띄어쓰기 정확하게!

나쁜 예: "감기몸살병원"

좋은 예: "감기 몸살 병원"

➡️ 단어마다 띄어쓰기!

3️⃣ 지역 이름 추가하기!

일반 검색: "맛집"

좋은 검색: "강남 맛집" 또는 "판교 맛집"

➡️ 내가 있는 곳 이름을 넣어요!

💻 윤호와 함께 실습하기

📍 실습 1: 병원 찾기

할아버지가 감기에 걸리셔서 병원을 찾아야 해요.

검색어: "강남구 내과"

➡️ 지역 + 병원 종류

네이버 지도에서 병원 검색 결과
"지도에서 가까운 병원을 찾아요!"
👴 할아버지:

"오! 우리 집 근처 병원들이 쭉 나오네!"

🍲 실습 2: 레시피 찾기

할머니가 김치찌개 레시피를 찾고 싶어하세요.

검색어: "김치찌개 레시피 백종원"

➡️ 요리 이름 + 레시피 + 유명 요리사 이름

김치찌개 레시피 검색 결과
"맛있는 레시피를 찾았어요!"
👵 할머니:

"이제 알겠어! 유명한 요리사 이름을 넣으니까 훨씬 좋은 레시피가 나오네!"

🎤 음성 검색도 편해요

🗣️ 윤호의 팁: 음성으로 검색하기

✓ 마이크 버튼을 누르세요

✓ 천천히 또박또박 말하세요

✓ "강남역 맛집"처럼 짧게 말하세요

✓ 조용한 곳에서 하면 더 잘 돼요

👦 윤호 선생님:

"타이핑이 어려우시면 음성 검색을 쓰세요! 말만 하면 검색돼요!"

할머니가 음성 검색을 사용하는 모습
"음성으로도 검색할 수 있어요!"

📚 윤호의 검색 정리

💫 검색왕 되는 법

✓ 짧고 간단하게: 핵심 단어만 사용

✓ 띄어쓰기 정확히: 단어마다 띄어쓰기

✓ 지역 이름 추가: 내 동네 이름을 넣기

✓ 음성 검색 활용: 말로도 할 수 있어요

✓ 결과 잘 보기: 블로그, 카페, 뉴스 탭 확인

👵 할머니:

"윤호야, 정말 고맙다! 이제 검색이 재미있어졌어!"

👴 할아버지:

"우리 손자가 정말 훌륭한 선생님이구나!"

"A picture is worth a thousand words."
