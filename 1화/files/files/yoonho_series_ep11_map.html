📱 네이버 지도 시작하기

1️⃣ 네이버 지도 설치
가장 많이 쓰는 지도 앱!

1. 플레이 스토어 또는 앱스토어 열기

2. "네이버 지도" 검색

3. 초록색 아이콘 확인 후 설치

4. 첫 실행 시 권한 허용
→ 위치 권한 (내 위치 표시용)

무료예요! 돈 안 들어요!
2️⃣ 내 위치 확인하기
지금 어디에 있나요?

1. 네이버 지도 앱 열기

2. 오른쪽 아래 현재 위치 버튼 터치
(동그란 표적 모양)

3. 파란 점이 내 위치!
→ 지도가 자동으로 이동
→ 주변 건물, 가게 보여요

4. 지도 확대/축소
→ 손가락 두 개로 벌리기/오므리기
→ + / - 버튼으로도 가능

🔍 목적지 검색하기

👵 할머니
병원 이름으로
검색하면 되는 거야?
👦 윤호
네! 할머니!
이름, 주소, 전화번호
뭐든 검색 가능해요!

예를 들어:
• "OO병원"
• "서울시 강남구 OO동"
• "맛집" "카페" 같은 키워드도 돼요!
🔎 검색 방법
단계별 따라하기:

1단계: 위쪽 검색창 터치

2단계: 목적지 이름 입력
→ 예: "서울역"
→ 자동 완성으로 추천!

3단계: 원하는 장소 선택
→ 목록에서 터치

4단계: 상세 정보 확인
→ 주소, 전화번호
→ 영업시간, 리뷰
→ 사진도 볼 수 있어요!

🚶 길찾기 시작하기

🗺️ 길찾기 버튼
3가지 방법 비교!

1. 길찾기 버튼 터치
→ 목적지 정보 화면에서 파란 버튼

2. 교통수단 선택:

🚶 도보
→ 걸어서 가는 시간
→ 산책로 표시

🚌 대중교통 (추천!)
→ 버스, 지하철 경로
→ 소요 시간, 요금
→ 환승 정보

🚗 자동차
→ 운전 경로
→ 택시 예상 요금

3. "길안내 시작" 버튼!

🚌 버스·지하철 타는 법

🚍 대중교통 길찾기
자세한 안내!

표시되는 정보:

📍 출발지
→ 내 현재 위치

🚌 버스 번호
→ 몇 번 버스 타야 하는지
→ 몇 정거장 가야 하는지
→ 버스 올 때까지 몇 분?

🚇 지하철 호선
→ 몇 호선 타야 하는지
→ 어느 역에서 내려야 하는지
→ 환승은 어디서?

📍 도착지
→ 내려서 어디로 걸어가는지
