✍️ 3. 좋은 이미지 설명 작성법

💡 핵심 포인트 5가지

1. 주제를 명확하게
❌ "예쁜 풍경"
✅ "한옥 마을의 봄날 풍경"

2. 분위기 설명 추가
"따뜻한", "평화로운", "활기찬"
3. 색상 언급
"파스텔 톤", "따뜻한 색감", "선명한 색"
4. 구도 지정
"정면에서 본", "위에서 내려다본"
5. 스타일 명시
"사진 같은", "수채화", "만화 스타일"

🆓 4. 무료 도구: Bing Image Creator

완전 무료로 시작하기!

1단계: bing.com/create 접속

2단계: 마이크로소프트 계정으로 로그인
(없으면 무료 가입)
3단계: 상단 입력창에 한글로 설명 입력
4단계: "만들기" 버튼 클릭!
5단계: 결과 확인 (4장 생성됨)
6단계: 마음에 드는 이미지 다운로드

💡 Bing의 장점

✅ 완전 무료

✅ 한글 지원 완벽
✅ 빠른 생성 (1-2분)
✅ 회원가입만으로 사용
✅ 제한 없음 (일정량까지)

⚠️ 6. 주의사항

꼭 기억하세요!

1. 저작권 확인
생성한 이미지도 상업적 사용 전 확인 필요

2. 실존 인물 주의
유명인이나 실제 사람 이름 사용 자제
3. 완벽하지 않아요
손가락, 얼굴이 이상할 수 있음
여러 번 시도해보기!
4. 개인정보 보호
집 주소, 전화번호 등 포함 금지
