📝 PHASE 1: Episode 16 콘텐츠 교체

🎯 이 단계의 목표

기존 Episode 16을 수정된 최신 버전으로 교체합니다.
중복 hero-section이 제거되고, 깨끗한 코드로 업데이트됩니다.

⏱️ 소요 시간: 5분
📌 URL 변경: 없음 (그대로 유지)

1

티스토리 관리자 접속

  • www.tistory.com 접속 후 로그인
  • 우측 상단 "관리" 버튼 클릭
  • 또는 주소창에 직접 입력:
    yourblog.tistory.com/manage
2

Episode 16 글 찾기

  • 좌측 메뉴에서 "글 관리" 클릭
  • 글 목록에서 스크롤하여
    "윤호와 함께하는 AI 이야기 - 16편: AI로 그림 그리기" 찾기
  • 마우스를 제목 위로 놓으면 오른쪽에 수정, 삭제, 통계, 비공개 메뉴가 나타나는데, 그 중 '수정'을 클릭
3

HTML 모드로 전환

  • 에디터 상단 도구모음에서
  • 맨 오른쪽의 '기본모드'를 누르고
  • 아래쪽에 나타나는 '기본모드' '마크다운' 'HTML' 중에
    "HTML" 또는 "<>" 아이콘 클릭
  • 기존 HTML 코드가 화면에 표시됨
4

기존 코드 전체 삭제

  • Ctrl + A (Windows) 또는
    Cmd + A (Mac) → 전체 선택
  • Delete 키 → 기존 코드 전체 삭제
  • 편집기가 비어있는 상태 확인
5

새 코드 붙여넣기

  • 다운로드한 episode_16_ai_image_generation.html 파일을
    메모장 또는 텍스트 에디터로 열기
  • Ctrl + A (전체 선택)
  • Ctrl + C (복사)
  • 티스토리 HTML 편집기로 돌아와서
  • Ctrl + V (붙여넣기)
  • 새 코드가 잘 붙여넣어졌는지 확인
6

발행하기

  • 에디터 하단의 "완료" 버튼 클릭
    (이미 완료된 글이면 "수정" 버튼)
  • 팝업이 뜨면 확인
  • 발행 완료 메시지 확인
7

확인하기

  • 블로그로 이동하여 Episode 16 열기
  • Ctrl + F5 (강력 새로고침)
  • Hero-section이 하나만 보이는지 확인
  • 콘텐츠가 깨끗하게 표시되는지 확인

✅ PHASE 1 완료!

Episode 16이 최신 버전으로 교체되었습니다!

🎨 PHASE 2: 스킨 CSS 수정 (95% 화면 차지)

🎯 이 단계의 목표

티스토리 스킨에 CSS를 추가하여
콘텐츠가 화면의 95%를 차지하도록 만듭니다.

⏱️ 소요 시간: 10분
🔧 난이도: 중급 (복사-붙여넣기만 하면 됨!)

⚠️ 중요: 백업하세요!

스킨 HTML을 수정하기 전에
반드시 현재 스킨 코드를 복사해서 백업해두세요!

만약 문제가 생기면 백업한 코드로 복원할 수 있습니다.

📋 방법 A: 스킨 CSS 수정 (가장 확실)

1

티스토리 스킨 편집 페이지 접속

  • 티스토리 관리자 페이지 접속
  • 좌측 메뉴에서 "꾸미기" 클릭
  • "스킨 편집" 버튼 클릭
  • "HTML 편집" 버튼 클릭
  • 스킨의 HTML 코드가 표시됨
2

백업하기 (중요!)

  • Ctrl + A → 전체 선택
  • Ctrl + C → 복사
  • 메모장을 열어서 Ctrl + V → 붙여넣기
  • 스킨백업_날짜.txt로 저장
3

CSS 추가 위치 찾기

  • Ctrl + F → 검색창 열기
  • </head> 검색
  • </head> 태그 바로 위에
    커서를 위치시킵니다
4

아래 CSS 복사 & 붙여넣기

아래 CSS 코드를 전체 복사해서
</head> 바로 위에 붙여넣으세요! 

<style>
/* ================================================
   윤호와 함께하는 AI 이야기 - 95% 화면 차지
   티스토리 스킨 최적화 CSS
   ================================================ */

/* 1. 사이드바 완전 제거 */
#sidebar, .sidebar, #blogMenu, .blog_menu, #blogProfile, 
.blog-profile, #rightMenu, .right-menu, .side_blogger, 
.another_category, #mCategory, .category-wrapper, .widget, 
.blog-widget, aside, [class*="sidebar"], [id*="sidebar"],
.side-area, #side-area, .blog-side {
    display: none !important;
    width: 0 !important;
    visibility: hidden !important;
}

/* 2. 전체 레이아웃 100% */
body, html, #wrap, #wrapper, #container, #main, #content,
.wrap, .wrapper, .main, .content, #tt-body-page, #mArticle {
    width: 100% !important;
    max-width: 100% !important;
    margin: 0 !important;
    padding: 0 !important;
}

/* 3. 글 내용만 95% */
.tt_article_useless_p_margin, .article-view, .entry-content,
.article-content, .post-content, article, .post, .entry {
    width: 95% !important;
    max-width: 95% !important;
    margin: 0 auto !important;
    padding: 0 !important;
}

/* 4. 커스텀 클래스도 95% */
.hero-section, .container {
    width: 95% !important;
    max-width: 95% !important;
    margin: 30px auto !important;
}

/* 5. Float 제거 */
.content-wrapper, .main-content {
    float: none !important;
    width: 100% !important;
}
</style>
5

적용 & 확인

  • 우측 상단의 "적용" 버튼 클릭
  • "저장되었습니다" 메시지 확인
  • 블로그로 이동
  • Ctrl + F5 (강력 새로고침)
  • 콘텐츠가 95% 차지하는지 확인!

📋 방법 B: 사이드바 없는 스킨 사용 (더 쉬움)

CSS 수정이 어렵다면?
아예 사이드바가 없는 스킨으로 변경하는 것도 방법입니다!

절차:

  1. 관리자 → "꾸미기" → "스킨 선택"
  2. "반응형" 또는 "심플" 카테고리 선택
  3. 사이드바 없는 1단 레이아웃 스킨 찾기
  4. "적용하기" 클릭
  5. Episode가 자동으로 95% 차지!

🔧 문제 해결

Q1. Episode는 교체했는데 여전히 좁게 보여요

원인: PHASE 2를 완료하지 않았습니다.

해결: 위의 "PHASE 2: 스킨 CSS 수정"을
반드시 완료해야 95% 화면을 차지할 수 있습니다!

Q2. CSS를 추가했는데도 변화가 없어요

원인: 브라우저 캐시 문제

해결 방법:
1. Ctrl + F5 (강력 새로고침)
2. 브라우저 캐시 완전 삭제:
- Ctrl + Shift + Delete
- 모든 쿠키와 캐시 삭제
- 브라우저 재시작
3. 다른 브라우저로 확인 (Chrome, Edge, Firefox)
4. 시크릿 모드로 확인 (Ctrl + Shift + N)

Q3. Hero-section이 여전히 두 개 보여요

원인: PHASE 1에서 기존 코드를 완전히 삭제하지 않았습니다.

해결:
1. 다시 Episode 16 수정 모드로 진입
2. HTML 모드로 전환
3. Ctrl + A → Delete (전체 삭제)
4. 새 코드만 붙여넣기
5. 발행

Q4. 스킨 CSS를 추가했더니 다른 글도 영향을 받아요

설명: 정상입니다!

스킨 CSS는 블로그 전체에 적용되므로
모든 글이 95% 화면을 차지하게 됩니다.

만약 Episode 16만 95%로 만들고 싶다면:
방법 B(스킨 변경)는 사용할 수 없고,
Episode 16의 CSS에만 특수한 ID를 부여하는
고급 방법이 필요합니다. (별도 문의)

💡 개발자 도구로 확인하기

F12를 눌러 개발자 도구를 열고:

1. Elements 탭 선택
2. 콘텐츠 영역 선택 (화살표 아이콘 클릭 후 콘텐츠 클릭)
3. 우측 Styles 패널에서 width 확인
4. width: 95%가 적용되어 있는지 확인
5. 만약 다른 값이면 어떤 CSS가 덮어쓰고 있는지 확인

❓ 자주 묻는 질문 (FAQ)

Q1. Episode 16 교체 시 URL이 바뀌나요?

A: 아니요! 기존 글을 직접 수정하는 방식이므로
URL은 그대로 유지됩니다. 댓글, 조회수도 모두 유지됩니다.

Q2. 혹시 실수로 잘못 수정하면 어떻게 하나요?

A: 걱정하지 마세요!
- 글 수정: 티스토리가 자동으로 이전 버전 저장 (휴지통에서 복구 가능)
- 스킨 수정: PHASE 2 시작 전 백업한 코드로 복원 가능

Q3. 모바일에서도 잘 보이나요?

A: 네! Episode 16은 반응형으로 제작되어
PC, 태블릿, 스마트폰 모두에서 최적화된 화면으로 보입니다.

Q4. 다른 Episode도 같은 방법으로 교체할 수 있나요?

A: 네! PHASE 1의 방법을 사용하여
모든 Episode를 같은 방식으로 교체할 수 있습니다.
PHASE 2는 한 번만 하면 모든 글에 적용됩니다.

Q5. CSS 코드를 이해하지 못해도 괜찮나요?

A: 네! 복사-붙여넣기만 하면 됩니다.
코드를 이해할 필요 없이 그대로 따라하시면
완벽하게 작동합니다.

Q6. 특정 글만 95%로 만들 수 있나요?

A: 스킨 CSS 수정 방법(방법 A)을 사용하면
블로그 전체가 95%가 됩니다.

특정 글만 95%로 만들려면 고급 방법이 필요하므로
별도로 문의해주세요.
