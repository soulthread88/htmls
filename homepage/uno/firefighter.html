소방관 안전 솔루션

Smart Name 태그 · 무선 메쉬 기반 화재 정보수집장치
// 한눈에 보기

유노시스템의 소방관 안전 솔루션은 통신 환경이 열악한 고위험 화재 현장을 위한 두 가지 제품입니다. 소방관 Smart Name 태그는 소방관의 이름·소속, 산소통 잔량, 생체 센서에 의한 위급 상태, 고도 센서에 의한 위치, 현장 출입 상태를 RF Mesh 네트워크로 소방대장에게 실시간 알리고 소방대장의 명령을 전달하는 양방향 시스템입니다. 무선 메쉬 기반 화재 정보수집장치는 소방관 진입 전에 카메라 영상(JPEG 1 FPS, 160°)·온도(-40~380°)·산소 포화도(0~25%) 정보를 100m 이상 거리에서 실시간 전달합니다.

소방관 Smart Name 태그

// FAQ

자주 묻는 질문

소방관 Smart Name 태그는 어떤 정보를 전달하나요?

소방관의 소속과 이름, 산소통 잔량, 생체 센서로 감지한 위급 상태, 고도 센서로 파악한 위치, 화재 현장 출입 상태를 소방대장에게 알리고, 소방대장의 명령을 현장 소방관에게 전달해 표시합니다.

무선 메쉬 화재 정보수집장치의 사양은?

카메라 영상 JPEG·1 FPS·160°, 측정 온도 -40~380°, 산소 포화도 0~25%, 통신 거리 100m 이상이며, 야간 영상을 주간 영상처럼 보이게 하는 필터를 갖췄습니다.
