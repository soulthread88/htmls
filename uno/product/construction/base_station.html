건설 현장
베이스 스테이션(기준국)

UNO SYSTEM|CONST-BS

스마트 건설 블랙박스와 연동하여 현장 내 통신 음영 구역을 해소하는 현장 기지국입니다. 블랙박스에서 수집된 GPS 위치·안전 데이터를 집중·중계하여 관제 서버로 안정적으로 전송하며, 현장 통신 인프라의 핵심 허브 역할을 수행합니다.

블랙박스 허브통신 음영 해소데이터 집중·중계LTE / Wi-Fi옥외형 설계다수 단말 동시 접속

// Features

주요 특징

📡
블랙박스 데이터 집중
현장 내 다수의 스마트 건설 블랙박스로부터 GPS 위치, 충격 감지, 영상 데이터를 수집·집중하여 관제 서버로 안정적으로 전달합니다.
🖼
이미지/영상
🔗
통신 음영 구역 해소
건물 사이, 지하, 굴착 현장 등 LTE 신호가 약한 구역에 배치하여 블랙박스가 항상 관제 서버와 연결될 수 있도록 통신 커버리지를 확장합니다.
🖼
이미지/영상
🌐
이중 통신 경로
LTE 주 통신과 Wi-Fi 부 통신을 이중으로 운용하여 통신 장애 시 자동 절체합니다. 데이터 손실 없는 안정적인 중계를 보장합니다.
🖼
이미지/영상
🛡️
옥외 설치 대응 설계
IP65 이상 방수·방진, 폭넓은 동작 온도(-20 ~ 60 °C)로 건설 현장의 혹독한 환경을 견딥니다. 폴 마운트·벽면 설치가 모두 가능합니다.
🖼
이미지/영상
⚡
PoE / 태양광 전원
PoE(Power over Ethernet) 또는 태양광 패널로 전원을 공급할 수 있어 전원 인프라가 없는 현장에도 유연하게 설치합니다.
🖼
이미지/영상
📊
원격 관리
현장 방문 없이 원격으로 베이스 스테이션(기준국) 상태를 모니터링하고 설정을 변경합니다. 장애 발생 시 즉시 알림을 관제 서버에 전송합니다.
🖼
이미지/영상

// System Configuration

시스템 구성

STEP 01
📦
스마트 건설 블랙박스
건설 현장의 장비·차량·작업자에 부착된 스마트 블랙박스가 GPS 위치(30cm 정밀도), 충격·진동, 영상 데이터를 실시간으로 수집합니다. LTE/Wi-Fi 이중 통신으로 데이터를 베이스 스테이션(기준국)으로 전송하며, 단말기당 최대 수백 대를 동시 지원합니다.
  • GPS 30cm 정밀 측위 — SBAS/RTK 보정 지원
  • 충격·전복·도난 이벤트 자동 감지
  • LTE + Wi-Fi 이중 통신 내장
  • IP67 방진·방수, -30 ~ 70 °C 동작
+

이미지 삽입
STEP 02
📡
베이스 스테이션(기준국)
현장 내 전략적 거점에 설치된 베이스 스테이션(기준국)이 다수의 블랙박스로부터 수집된 데이터를 집중·중계합니다. LTE 주 통신과 Wi-Fi 보조 통신을 이중으로 운용하여 통신 음영 구역을 해소하고, 장애 시 자동 절체로 무중단 데이터 전송을 보장합니다.
  • 다수 블랙박스 동시 접속 지원 (최대 수백 대)
  • LTE/Wi-Fi 이중 통신 자동 절체
  • IP65 옥외 방수·방진, 폴·벽면 설치
  • PoE 또는 태양광 전원 공급 가능
  • 원격 모니터링 및 설정 변경 지원
+
클릭하여
이미지 삽입
STEP 03
🖥️
GIS 관제 서버
베이스 스테이션(기준국)에서 집중된 데이터를 수신한 GIS 관제 서버가 현장 전체를 실시간으로 통합 관제합니다. 지도 기반 장비·차량·작업자 위치를 한눈에 확인하고, 이벤트 발생 시 즉시 경보를 발령합니다. 이력 데이터 분석으로 안전사고 예방과 시공 효율 최적화를 지원합니다.
  • GIS 기반 실시간 위치·상태 통합 관제
  • 충격·도난·이탈 이벤트 즉시 경보
  • 이력 데이터 분석 및 시공 보고서 자동 생성
  • Modbus / BACnet / TCP-IP 프로토콜 지원
