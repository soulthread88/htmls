안녕하세요!
<시니어 AI 공부 시리즈>의 든든한 가이드 윤호입니다.
"외국 뉴스를 보고 싶은데 영어를 몰라서 못 보겠어요."
오늘은 영어를 몰라도 해외 뉴스와 영상을 한글로 자동 번역해서 보는 방법과 이상한 번역을 구분하는 법을 배울 거예요!
🌸 오늘의 사자성어
不恥下問
(불치하문)
아랫사람에게 묻는 것을 부끄러워하지 않음.
외국어를 모른다고 해서 세계 소식에 관심을 갖지 못할 이유는 없습니다. 새로운 기술을 배우고, 자동 번역 기능을 활용하는 것. 모르는 것을 부끄러워하지 않고 배우려는 자세가 바로 불치하문의 정신입니다.
🌸 오늘의 AI 용어
자동 번역 (Automatic Translation)
뜻: AI가 외국어 텍스트나 음성을 자동으로 다른 언어로 바꿔주는 기술
쉬운 설명: 컴퓨터가 영어를 한글로, 한글을 영어로 순식간에 바꿔주는 통역사 역할을 합니다. 구글 번역, 파파고, 유튜브 자막 등이 대표적인 예입니다.
자막 (Subtitle)
뜻: 영상 하단에 나타나는 대사나 설명 글자
쉬운 설명: 영화나 영상을 볼 때 화면 아래에 뜜는 글자예요. 유튜브에서는 자동으로 음성을 인식해서 자막을 만들고, 이걸 다시 한글로 번역해 줄 수 있어요.
기계 번역 (Machine Translation)
뜻: 사람이 아닌 컴퓨터 프로그램이 자동으로 언어를 번역하는 것
쉬운 설명: 사람 통역사가 아니라 AI가 번역하는 것이에요. 그래서 가끔 어색하거나 이상한 문장이 나올 수 있지만, 대략적인 의미는 충분히 이해할 수 있습니다.
🌸 영어 몰라도 괜찮습니다
문제 상황: CNN이나 BBC 같은 해외 뉴스를 보고 싶은데 영어를 전혀 모릅니다.
해결 방법:
1. 유튜브에서 해외 뉴스 찾기: 유튜브에서 'CNN news', 'BBC news', 'NHK news' 등을 검색하세요.
2. 자막 켜기: 영상을 재생한 후 오른쪽 아래 'CC' 버튼(자막 버튼)을 누르세요. 영어 자막이 나타납니다.
3. 한글로 번역하기: 자막이 켜진 상태에서 톱니바퀴 모양(설정) → 자막 → 자동 번역 → 한국어를 선택하면 한글 자막으로 바뀝니다.
💡 꿀팁: 질문: 자막이 너무 빨리 지나가서 읽기 힘들어요. 어떻게 하죠? → 영상 속도를 늦출 수 있어요! 톱니바퀴(설정) → 재생 속도 → 0.75배속 또는 0.5배속을 선택하면 천천히 볼 수 있습니다.
🌸 번역 버튼 위치
문제 상황: 외국 웹사이트나 뉴스 기사를 번역하고 싶은데 번역 버튼이 어디 있는지 모르겠어요.
해결 방법:
1. 크롬 브라우저 자동 번역: 외국어 웹페이지를 열면 주소창 오른쪽에 번역 아이콘(언어 모양)이 나타납니다. 이걸 누르고 '한국어로 번역'을 선택하세요.
2. 네이버 파파고 앱: 파파고 앱을 열고 '웹사이트 번역' 메뉴를 선택한 후 외국 사이트 주소를 붙여넣으면 전체 페이지가 번역됩니다.
3. 구글 번역 사용: 구글 번역(translate.google.com)에 접속해서 '웹사이트' 탭에 주소를 입력하면 번역된 페이지를 볼 수 있어요.
💡 꿀팁: 질문: 스마트폰에서도 웹페이지를 번역할 수 있나요? → 네! 크롬 앱에서 외국어 페이지를 열면 하단에 '번역' 버튼이 나타납니다. 혹은 오른쪽 위 점 3개(메뉴) → 번역을 선택하세요.
🌸 이상한 번역 구분법
문제 상황: 자동 번역을 사용하니 "그는 사과를 먹었다"가 "그는 미안하다를 먹었다"처럼 이상하게 나와요. 뭘 믿어야 할까요?
해결 방법:
1. 전체 맥락 파악하기: 한 문장만 보지 말고 앞뒤 문장을 함께 읽어서 전체 의미를 추측하세요. 이상한 단어가 있어도 맥락으로 이해할 수 있어요.
2. 여러 번역 비교: 구글 번역과 파파고를 둘 다 사용해서 결과를 비교하면 더 정확한 의미를 알 수 있습니다.
3. 고유명사 주의: 사람 이름, 지명, 회사명 같은 고유명사는 번역이 틀릴 확률이 높습니다. 원문을 확인하거나 검색해 보세요.
💡 꿀팁: 질문: 번역이 이상하면 원문을 볼 수 있나요? → 네! 유튜브 자막에서는 톱니바퀴(설정) → 자막 → 영어를 선택하면 원래 언어로 볼 수 있어요. 웹페이지에서는 주소창의 번역 아이콘 → 원본 표시를 누르면 됩니다.
🌸 시니어 꿀팁!
💡 꿀팁 1: 질문: 외국 드라마나 영화도 한글 자막으로 볼 수 있나요? → 유튜브에 올라온 외국 콘텐츠는 자동 번역 자막을 쓸 수 있어요. 넷플릭스나 디즈니플러스 같은 정식 서비스는 처음부터 한글 자막이 제공됩니다.
💡 꿀팁 2: 질문: 번역된 뉴스를 저장해서 나중에 다시 볼 수 있나요? → 웹페이지는 북마크(즐겨찾기)에 저장할 수 있고, 유튜브 영상은 '저장' 버튼을 눌러 재생목록에 추가하면 언제든 다시 볼 수 있어요.
💡 꿀팁 3: 질문: 음성으로도 번역할 수 있나요? → 네! 구글 번역이나 파파고 앱에서 마이크 버튼을 누르고 외국어를 말하면 즉시 한글로 번역해 줍니다. 여행 갈 때 정말 유용해요.
🌸 한글 맞춤법 / 문법 코너
1. "번역하다 vs 번역되다"
X 틀린 것: 영어를 번역되었어요
O 맞는 것: 영어를 번역했어요 / 영어가 번역되었어요
해설: '번역하다'는 능동, '번역되다'는 피동입니다. '영어를'이면 '번역했어요', '영어가'면 '번역되었어요'를 써야 해요.
예문: 파파고가 문장을 번역했어요 / 문장이 자동으로 번역되었어요
2. "자막 vs 자막이"
X 틀린 것: 자막 켜졌어요
O 맞는 것: 자막이 켜졌어요 / 자막을 켰어요
해설: 주어에는 조사 '이/가'를, 목적어에는 '을/를'을 붙여야 합니다.
예문: 자막이 화면에 나타났어요 / 자막을 한글로 바꿨어요
3. "되요 vs 돼요"
X 틀린 것: 번역이 되요
O 맞는 것: 번역이 돼요
해설: '되어요'의 줄임말은 '돼요'입니다. '되+어→돼'로 합쳐집니다.
예문: 자동 번역이 잘 돼요 / 한글로 변환이 돼요

🌸 오늘의 퀴즈 정답
A1. 자동 번역 - AI가 외국어를 즉시 다른 언어로 바꿔주는 기술로, 구글 번역, 파파고, 유튜브 자막 등에서 사용됩니다.
A2. 자막 - 영상 하단에 나타나는 대사나 설명 글자로, 청각 장애인을 위해서도 사용되지만 외국어 번역에도 유용합니다.
A3. CC 버튼 - 'Closed Caption'의 약자로, 유튜브 영상 오른쪽 아래에 있는 자막 켜기/끄기 버튼입니다.
🌸 오늘의 사자성어 풀이
不恥下問(불치하문)을 풀어보면:
不(불): 아니 불 - 부정, ~하지 않다
恥(치): 부끄러워할 치 - 수치스럽게 여기다
下(하): 아래 하 - 아랫사람, 낮은 위치
問(문): 물을 문 - 질문하다, 묻다
해석: 아랫사람에게 묻는 것을 부끄러워하지 않음이라는 뜻.
외국어를 모른다고 해서 세계 소식을 포기할 필요는 없습니다. "이 버튼이 뭐지?" "자막은 어떻게 켜지?" 하고 물어보는 것, 새로운 기술을 배우려는 것은 전혀 부끄러운 일이 아닙니다. 오히려 나이가 들어서도 배우려는 자세야말로 가장 아름다운 모습입니다. 오늘 배운 자동 번역 기능을 활용해서 세계의 소식을 마음껏 접하고, 더 넓은 세상과 소통하는 지혜로운 시니어가 되어 봅시다!
