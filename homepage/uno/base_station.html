// 한눈에 보기

건설 현장 베이스 스테이션(기준국)은 현장 내 다수의 스마트 건설 블랙박스로부터 GPS 위치·충격·영상 데이터를 모아 GIS 관제 서버로 중계하는 현장 기지국입니다. LTE(Cat.4 이상) 주 통신과 Wi-Fi 부 통신을 이중으로 운용해 장애 시 자동 절체하며, IP65 이상 방수·방진, -20~60°C 동작, PoE·DC 12V·태양광 전원, 폴·벽면 설치를 지원합니다.

// System Configuration

시스템 구성

STEP 01
📦
스마트 건설 블랙박스
건설 현장의 장비·차량·작업자에 부착된 스마트 블랙박스가 GPS 위치(60cm 이내 정밀도), 충격·진동, 영상 데이터를 실시간으로 수집합니다. LTE/Wi-Fi 이중 통신으로 데이터를 베이스 스테이션(기준국)으로 전송하며, 단말기당 최대 수백 대를 동시 지원합니다.
  • GPS 60cm 이내 정밀 측위 — SBAS/RTK 보정 지원
  • 충격·전복·도난 이벤트 자동 감지
  • LTE + Wi-Fi 이중 통신 내장
  • IP67 방진·방수, -30 ~ 70 °C 동작

베이스 스테이션(기준국)

  • LTE/Wi-Fi 이중 통신 자동 절체
  • IP65 옥외 방수·방진, 폴·벽면 설치
  • PoE 또는 태양광 전원 공급 가능
  • 원격 모니터링 및 설정 변경 지원

GIS 관제 서버
베이스 스테이션(기준국)에서 집중된 데이터를 수신한 GIS 관제 서버가 현장 전체를 실시간으로 통합 관제합니다. 지도 기반 장비·차량·작업자 위치를 한눈에 확인하고, 이벤트 발생 시 즉시 경보를 발령합니다. 이력 데이터 분석으로 안전사고 예방과 시공 효율 최적화를 지원합니다.

  • 충격·도난·이탈 이벤트 즉시 경보
  • 이력 데이터 분석 및 시공 보고서 자동 생성

// FAQ

자주 묻는 질문

통신 장애 시에는 어떻게 되나요?

LTE 주 통신과 Wi-Fi 부 통신을 이중으로 운용해 장애가 나면 자동으로 절체하므로 데이터 손실 없이 중계합니다.

전원이 없는 현장에도 설치할 수 있나요?

PoE 또는 태양광 패널로 전원을 공급할 수 있어 전원 인프라가 없는 현장에도 설치할 수 있습니다.
