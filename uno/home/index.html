// Welcome

화재로부터 안전한 스마트 인프라

유노시스템㈜은 광섬유 센싱 기술을 기반으로 화재 감지와 소방통합감시시설, 스마트 건설 솔루션을 설계·공급하는 전문 기업입니다. 화재 수신기(Fire Alarm Control Panel), DTS/LHD 선형열감지, 분산음향센싱(DAS), SCADA 통합 감시, 스마트 건설 베이스 스테이션에 이르기까지 — 사람과 자산, 인프라를 지키는 신뢰성 높은 감시 시스템을 제공합니다.

// Solutions

핵심 솔루션

🎛️
화재 수신기 (FACP)
R형·P형 화재 수신기로 신뢰성 높은 화재 경보 제어를 제공합니다.
🌡️
선형열감지 DTS/LHD
광섬유 분산온도센싱으로 터널·전력구·산업 현장의 화재를 실시간 감지합니다.
📡
분산음향센싱 DAS
광케이블을 수천 개 감지점으로 전환해 침입·누출·이상을 탐지합니다.
🖥️
SCADA 통합 감시
다수 현장의 화재·설비 데이터를 단일 관제 화면으로 통합 관리합니다.
📦
베이스 스테이션 · Blackbox
스마트 건설 현장의 데이터 수집·전송 허브와 현장 기록 장치를 공급합니다.
🔗
네트워크 솔루션
L2 Ring·ERPS 기반 무중단 현장 네트워크로 안정적 데이터 전송을 보장합니다.

// Partner

글로벌 파트너십

유노시스템㈜은 광섬유 센싱 분야의 글로벌 리더 Bandweaver의 파트너로서, 검증된 광섬유 기술과 국내 소방·건설 현장 노하우를 결합해 최적의 감시 솔루션을 제공합니다. DTS·DAS 기반 화재 감지와 침입·누출 감시, 전력 케이블 상태 모니터링까지 — 신뢰성 높은 기술과 지속적인 기술 지원을 약속합니다. Honeywell, System Sensor, Nexen, Taihan 등 세계 굴지의 회사에 제품을 공급합니다.
