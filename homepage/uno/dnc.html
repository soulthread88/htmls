DNC

Data Network Controller  |  유노시스템㈜
// 한눈에 보기

DNC(Data Network Controller)는 L2 링(Ring) 스위치·TCP/IP 서버·수신기·FDF를 하나의 수납함에 담은 소방 네트워크 집중 장치입니다. 8 TP(1Gbps)+2 SFP 포트, 스위치 패브릭 20Gbps를 갖추고 ITU-T G.8032 ERPS와 S-Ring으로 링크 장애 시 자동 우회해, 변전소 ICT실 마스터와 환기구 슬레이브 수신기를 링으로 연결합니다.

05 · Features

주요 특징

🔄
Ring 방식 자가 복구
ITU-T G.8032 ERPS 및 S-Ring 지원으로 링크 장애 시 밀리초 단위 자동 우회 경로 전환. 소방 네트워크의 무중단 운영을 보장합니다.
🌐
고성능 L2 스위칭
8 TP(1Gbps) + 2 SFP(1G) 포트, Switch Fabric 20Gbps, Throughput 14.8Mpps. 대용량 데이터도 지연 없이 처리합니다.
🔒
보안 & VLAN 관리
802.1Q VLAN, IEEE 802.1x 인증, IGMP Snooping으로 네트워크 보안 세분화 및 멀티캐스트 트래픽 최적화를 구현합니다.
🏗️
견고한 수납 구조
케이스 460.4×378×120mm(IP 방수 GASKET 내장), 인쇄 가능 범위 320×420mm. 옥외·전력구 등 열악한 환경에 최적화된 설계.
⚡
저전력 고효율
최대전력 AC 7.6W, 무부하전력 3.15W. AC 100~240V 광폭 입력으로 다양한 현장 전원 조건에 적용 가능합니다.
🖧
마스터-슬레이브 토폴로지
S/S ICT실 마스터 ↔ 환기구 슬레이브 구성. P9(Blue)/P10(Red) 포트로 Ring 루프 완성. 최대 다수 슬레이브 노드 연결 지원.

// FAQ

자주 묻는 질문

링크 장애가 나면 어떻게 되나요?

ITU-T G.8032 ERPS와 S-Ring을 지원해 링크 장애 시 자동으로 우회 경로로 전환합니다.

전원과 동작 온도는?

AC 100~240V 입력, 최대 7.6W(무부하 3.15W)이며 0~60°C에서 동작합니다.
