🏦 은행 앱 시작하기

1️⃣ 은행 앱 다운로드
주요 은행 앱:

🏦 KB국민은행
🏦 신한은행
🏦 우리은행
🏦 하나은행
🏦 NH농협

다운로드 방법:
1. 플레이스토어 열기
2. 자기 은행 이름 검색
3. 다운로드 누르기
4. 설치 완료!

⚠️ 처음엔 자녀와 함께 설정하세요!
2️⃣ 앱 첫 설정
필요한 정보:

📝 계좌번호
📝 비밀번호 (4자리)
📝 주민등록번호
📝 보안카드 또는 OTP

본인 인증:
→ 휴대폰 인증
→ 지문 등록
→ 간편 비밀번호 설정

⚠️ 이 정보는 절대 남에게 알려주면 안 돼요!
3️⃣ 송금하는 방법
기본 송금 순서:

1. 은행 앱 열기
2. 이체 또는 송금 메뉴
3. 받는 사람 은행 선택
4. 계좌번호 입력
5. 금액 입력
6. 받는 사람 이름 확인
7. 비밀번호 입력
8. 송금 완료!

✅ 받는 사람 이름 꼭 확인하세요!

💡 편리한 추가 기능

⚡ 더 쉽게 보내는 방법

1. 자주 보내는 계좌 등록
→ 즐겨찾기 기능
→ 손주들 계좌 미리 저장
→ 다음엔 클릭 한 번!

2. 카카오페이로 송금
→ 카카오톡으로 보내기
→ 계좌번호 몰라도 OK
→ 이름만 알면 가능!

3. 예약 이체
→ 매달 같은 날 자동 송금
→ 용돈, 연금 이체에 편리

4. 잔액 확인
→ 내 계좌 얼마 있는지
→ 언제든 확인 가능!
