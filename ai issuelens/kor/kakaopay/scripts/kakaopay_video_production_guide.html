CapCut 숏폼 제작 절차 (공통)

1
CapCut 프로젝트 생성
New Project → 9:16 세로형(1080×1920) → 60fps 선택 → 배경 소재(빨간 컬러 배경 또는 화면 캡처 영상) 추가.
2
CapCut AI 자막 자동 생성
Text → Auto Captions → Korean 선택 → 자동 생성 후 타이밍 미세 조정. 스타일: 흰 텍스트 + 검정 외곽선 + 강조 단어 빨간색으로 수동 하이라이트.
3
CapCut 텍스트 애니메이션
Add Text → 숫자(4,045만, 542억) 입력 → Animation → "Typewriter" 또는 "Pop In" 효과. 색상 빨간 → 흰 전환으로 주목도 UP.
4
Galaxy.ai 또는 CapCut AI 목소리
CapCut Text-to-Speech: 대본 입력 → 한국어 남성 → 빠른 속도 1.1~1.2배 → 생성. 또는 Galaxy AI 보이스 생성 후 MP3 임포트.
5
CapCut BGM & 효과음
Audio → Search "긴장감 뉴스 배경음" → 볼륨 15~20%로 낮춤. 핵심 숫자 등장 시 "whoosh" 또는 "impact" 효과음 추가. 저작권 무료 확인 필수.
6
CapCut 컬러 그레이딩
Adjust → Saturation +10, Contrast +15, Shadows -10 → Filter에서 "News" 또는 "Dramatic" 프리셋 적용. 후반부 긴장감 구간은 색온도 -20.
7
내보내기 & 업로드
Export → 1080p · 60fps · H.265. 각 플랫폼별 업로드 시 제목에 숫자 필수 포함 (예: "4,045만명 피해 [충격]"). #Shorts 해시태그 3~5개.
