📱 영상통화 앱 알아보기

1️⃣ 주요 영상통화 앱
쉬운 순서대로:

💬 카카오톡 (제일 쉬워요!)
→ 이미 쓰고 계시면 바로 가능
→ 1:1 통화, 단체 통화 가능

📹 줌(Zoom)
→ 여러 명이 한꺼번에
→ 친구들과 모임할 때 좋아요

📞 페이스타임 (아이폰)
→ 아이폰끼리 통화

📱 구글 미트
→ 구글 계정으로 사용
2️⃣ 카카오톡 영상통화
영상통화 거는 법:

1. 카카오톡 열기
2. 통화하고 싶은 사람 채팅방 들어가기
3. 위쪽 전화 버튼 누르기
4. 영상통화 선택
5. 상대방이 받으면 시작!

영상통화 받는 법:

1. 전화 오면 화면에 알림
2. 초록색 버튼 누르기
3. 카메라 켜지면서 통화 시작!
3️⃣ 줌(Zoom) 사용하기
줌 시작하기:

1. 플레이스토어에서
"Zoom" 앱 다운로드

2. 회의 참가 누르기

3. 회의 ID 입력
(초대한 사람이 알려줘요)

4. 이름 입력하고 참가

5. 비디오로 참가 선택

줌 회의 만들기:
→ 조금 어려우니 자녀에게 도움 요청!

💡 영상통화 잘하는 팁

📸 화면 예쁘게 나오는 법

1. 밝은 곳에서 하세요
→ 창문 쪽 바라보고 앉기
→ 얼굴이 밝게 나와요

2. 스마트폰 높이 조절
→ 눈높이 정도로
→ 너무 아래서 찍으면 이상해요

3. 배경 정리
→ 뒤에 지저분한 거 치우기
→ 깔끔한 벽이 좋아요

4. 이어폰 사용
→ 소리가 더 잘 들려요
→ 울림 현상도 없어요
