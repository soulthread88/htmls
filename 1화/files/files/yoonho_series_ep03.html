🎯 검색의 3가지 비밀

1️⃣ 짧고 명확하게!
❌ 나쁜 예: "김치찌개를 맛있게 끓이려면 어떻게 해야 하나요?"

2️⃣ 띄어쓰기 정확하게!
❌ 나쁜 예: "감기몸살병원"
✅ 좋은 예: "감기 몸살 병원"

단어마다 띄어쓰기!
3️⃣ 음성 검색 활용!
마이크 버튼 🎤 누르고
"무릎에 좋은 운동" 이라고 말하면 끝!

타자 안 쳐도 돼요!

⚠️ 주의할 점

🚨 이것만은 조심!

  • 광고 구분하기! (위쪽은 광고예요)
  • 너무 비싼 병원, 가격 먼저 확인!
  • 리뷰 개수 적은 곳은 조심!
  • 전화번호 누르면 통화료 나가요
  • 낯선 사이트 주소 함부로 클릭 NO!

✨ 검색 고수가 되는 꿀팁

🏆 프로의 팁

1. 사진으로 검색
사진 찍어서 "이미지 검색"하면
비슷한 물건 찾아줘요!

2. 음성 명령
"하이 클로바" 부르고
질문하면 답해줘요!

별표(⭐) 눌러서 저장!

4. 최근 검색
검색창 누르면
전에 찾았던 것 다시 나와요!
