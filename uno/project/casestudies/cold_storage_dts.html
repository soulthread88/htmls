// 광케이블식 화재감지

냉동창고 광케이블식
화재감지기 (DTS)

UNO SYSTEM|Bandweaver FireLaser DTS · 차동식분포형 광케이블식 감지기

-30°C 이하 냉동·냉장 환경에서도 결로·착상·전자파 영향 없이 광케이블 한 가닥으로 전 구간 온도를 연속 측정하는 분산온도감지(DTS) 방식의 선형 정온식 화재감지 시스템입니다. 감지부에 전자부품이 없어 극저온·고습 환경에 최적화되어 있습니다.

// Features

주요 특징

🧊
결로·착상 무영향
감지 케이블이 온도 변화만 감지하는 수동 광소자로, 냉동 구역 특유의 결로·서리·성에가 발생해도 오동작이나 미감지 없이 안정적으로 동작합니다.
🖼
이미지/영상
🔌
감지부 무전원·무전자
냉동 구역 내부에 전자부품과 전원이 없어 극저온에서의 소자 열화나 배터리 방전 문제가 없으며 본질안전 구조입니다.
🖼
이미지/영상
📏
전 구간 연속 온도감시
케이블 전 길이를 수 미터 간격으로 연속 측정하여 국소 발열과 화점을 ±1m 이내로 위치까지 특정합니다.
🖼
이미지/영상
⚡
전자파·낙뢰 면역
광신호 기반이므로 냉동기·인버터·모터에서 발생하는 전자파(EMI)와 낙뢰의 영향을 받지 않습니다.
🖼
이미지/영상
🌡️
정온식·차동식 복합 판정
절대온도(정온식)와 온도상승률(차동식)을 동시에 판정하여 냉동환경의 정상 온도변동과 화재를 구분해 오보를 최소화합니다.
🖼
이미지/영상
🛠️
장수명·저유지보수
광케이블 자체가 감지소자이므로 구간별 감지기 교체가 필요 없고, 넓은 랙 창고를 케이블 포설만으로 커버합니다.
🖼
이미지/영상

// System Configuration

시스템 구성

STEP 01
📡
광케이블 감지 포설
냉동창고 천장과 랙을 따라 감지용 광케이블을 연속 포설합니다.
  • 랙 상단·통로 천장을 따라 연속 포설
  • 단일 채널 최대 8km 포설
  • 결로·저온 구간 무영향
  • 방수·방진 커넥터 적용

  • 라만 후방산란광 분석
  • 구간별 온도·상승률 실시간 산출
  • 정온·차동 임계 판정
