📱 건강 관리 앱 활용하기

1️⃣ 약 알람 설정하기
추천 앱:

💊 약 먹을 시간 (무료)
💊 삐약삐약 (무료)
💊 케어링 (무료)

설정 방법:
1. 앱 다운로드
2. 약 이름 입력
3. 복용 시간 설정
4. 알람 켜기

시간 되면 알림이 울려요!
2️⃣ 혈압·혈당 기록하기
건강 기록 앱:

❤️ 삼성 헬스
❤️ 애플 건강
❤️ 케어링

기록 방법:
1. 앱 열기
2. 혈압 또는 혈당 선택
3. 측정한 수치 입력
4. 저장 누르기

그래프로 변화 확인!
가족과 공유도 가능!
3️⃣ 병원 앱 활용하기

🏥 삼성서울병원
🏥 세브란스
🏥 서울대병원

할 수 있는 것:
📅 진료 예약
📋 검사 결과 확인
💳 진료비 결제
📄 처방전 보기
🚗 주차 정보 확인

👉 오늘의 실습

🎯 건강 앱 시작하기!
1단계 플레이스토어에서
"약 먹을 시간" 앱 다운로드
2단계 앱 열고 약 추가 누르기
3단계 약 이름과 복용 시간 입력
(예: 혈압약, 아침 8시)
4단계 알람 켜기
5단계 설정한 시간에 알림 오는지 확인!
🎉 알림 왔다면 성공! 🎉
