🎬 유튜브 활용하기

1️⃣ 요리 영상 보기
추천 채널:

👨‍🍳 백종원의 요리비책
→ 쉽고 간단한 요리

👩‍🍳 만개의레시피
→ 다양한 요리법

👵 엄마의 손맛
→ 전통 요리

검색하는 법:
1. 유튜브 앱 열기
2. 위쪽 돋보기 누르기
3. "김치찌개 만들기" 검색
4. 영상 골라서 시청!

💡 속도 조절도 가능해요!
(톱니바퀴 → 재생 속도)
2️⃣ 운동 앱 활용하기
추천 운동 앱:

🚶 삼성 헬스
→ 걸음 수, 칼로리
→ 심박수 측정

🏃 워크온
→ 걷기 미션
→ 포인트 적립!

🧘 홈트 유튜브 채널
→ 스트레칭 영상
→ 의자 운동

걷기 기록하기:
1. 앱 열고 걷기 선택
2. 시작 버튼 누르기
3. 산책 다녀오기
4. 종료하면 자동 저장!

✅ 가족과 걸음 수 대결도 가능!
3️⃣ 음악 듣기
음악 앱:

🎵 유튜브 뮤직 (무료)
→ 광고 있지만 무료
→ 모든 노래 검색 가능

🎵 멜론 (유료)
🎵 지니뮤직 (유료)
🎵 벅스 (유료)
→ 광고 없이 깨끗하게

검색하는 법:
1. 앱 열기
2. "진성 트로트" 검색
3. 듣고 싶은 노래 재생
4. 재생목록 만들기!

💡 좋아하는 노래는
보관함에 저장하세요!
