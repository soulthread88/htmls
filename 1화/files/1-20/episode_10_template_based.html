✍️ AI에게 그림 주문하는 방법

📝 구체적으로 설명하기

"강아지" 보다 "푸들 강아지가 공원에서 노는 모습"

🎨 스타일 지정하기

"수채화 스타일", "만화 스타일", "사진처럼"

🌈 색상 언급하기

"따뜻한 색감", "파스텔톤", "밝고 화사하게"

📐 분위기 추가하기

"밝고 즐거운", "신비로운", "평화로운"

👉 오늘의 실습

🎯 AI로 첫 그림 만들기!

1단계: 빙 이미지 생성 접속 (bing.com/create)

2단계: 마이크로소프트 계정으로 로그인

3단계: "해변에서 노는 강아지" 입력

4단계: AI가 그린 그림 4개 확인

5단계: 마음에 드는 그림 다운로드

빙 이미지 생성 시작 화면
"1단계: 사이트 접속"
로그인 화면
"2단계: 계정 로그인"
텍스트 입력 화면
"3단계: 원하는 그림 설명 입력"
AI가 생성한 4개의 그림 결과
"4단계: 생성된 그림 확인"
다운로드 완료 화면
"5단계: 그림 저장 완료!"
