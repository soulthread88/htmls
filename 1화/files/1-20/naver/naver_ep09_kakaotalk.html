🌸 오늘의 AI 용어
🏵️ 5가지 핵심 용어
1. 접근성 (Accessibility)
뜻: 누구나 쉽게 사용할 수 있도록 돕는 기능
쉬운 설명: 나이나 시력에 상관없이 모든 사람이 편하게 쓸 수 있게 만드는 것입니다.
예시: 글자 크기 조절, 음성 안내, 고대비 색상
2. UI (User Interface)
뜻: 사용자가 보는 화면 디자인
쉬운 설명: 버튼, 메뉴, 아이콘이 어떻게 배치되어 있는지를 말합니다.
예시: 카카오톡의 채팅방 목록, 설정 메뉴 화면
3. UX (User Experience)
뜻: 사용자가 느끼는 전체적인 경험
쉬운 설명: 앱을 쓸 때 편한지, 복잡한지, 만족스러운지에 대한 느낌입니다.
예시: "설정이 쉽게 찾아진다" → 좋은 UX
4. 확대/축소 (Zoom)
뜻: 화면이나 글자를 크게 또는 작게 보는 기능
쉬운 설명: 손가락으로 화면을 벌리거나 오므려서 크기를 조절합니다.
예시: 사진을 두 손가락으로 벌리면 크게 보입니다
5. 설정 (Settings)
뜻: 앱의 기능을 내 마음대로 바꿀 수 있는 메뉴
쉬운 설명: 글자 크기, 알림 소리, 배경 색 등을 조절하는 곳입니다.
예시: 카카오톡 → 더보기 → 설정 → 화면

🌼 따라하기 쉬운 3단계
1단계 카카오톡 열기 → 오른쪽 아래 "더보기" 누르기

🌸 사자성어 풀이
明若觀火 (명약관화) 한자 풀이
명(明): 밝을 명. 밝고 환하다는 의미입니다.
약(若): 같을 약. ~와 같다, ~처럼이라는 의미입니다.
관(觀): 볼 관. 보다, 관찰하다는 의미입니다.
화(火): 불 화. 불, 화염이라는 의미입니다.
전체 의미: 불을 보듯이 분명하다는 뜻입니다.
글자를 크게 하면 모든 것이 명약관화처럼 선명하게 보입니다!

🌹 보조 용언 띄어쓰기
시니어분들이 자주 헷갈려 하시는 보조 용언 띄어쓰기를 알려드립니다.
📌 기본 원칙: 보조 동사(보조 용언)는 띄어 쓰는 것이 원칙이나, 붙여쓰기도 허용됩니다.
하지만 띄어 쓰는 것이 더 명확하고 정확합니다!
🌻
자주 틀리는 보조 용언
1. "~ 주다"
❌ 가르쳐주세요 → ⭕ 가르쳐 주세요
❌ 알려주세요 → ⭕ 알려 주세요
※ "~어/아 주다"는 띄어 써야 합니다.
2. "~ 보다"
❌ 해보세요 → ⭕ 해 보세요
❌ 읽어보세요 → ⭕ 읽어 보세요
※ "~어/아 보다"는 띄어 써야 합니다.
3. "~ 가다/오다"
❌ 커져가고 → ⭕ 커져 가고
❌ 늘어나가는 → ⭕ 늘어나 가는
※ "~어/아 가다/오다"는 띄어 써야 합니다.
4. "~ 버리다"
❌ 잊어버렸어요 → ⭕ 잊어버렸어요 (붙여 쓰기 가능)
❌ 지워버렸어요 → ⭕ 지워 버렸어요 (띄어쓰기 권장)
※ 붙여 써도 되지만, 띄어 쓰는 것이 더 명확합니다.
