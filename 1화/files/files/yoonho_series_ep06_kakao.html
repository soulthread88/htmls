📱 카카오톡 시작하기

1️⃣ 카카오톡 설치하기
앱 다운로드

1. 플레이 스토어 (안드로이드) 또는
앱스토어 (아이폰) 열기
2. "카카오톡" 검색
3. 설치 버튼 누르기
4. 노란색 말풍선 아이콘 확인!

무료예요! 돈 안 들어가요!
2️⃣ 카카오톡 가입하기
처음 시작

1. 카카오톡 앱 열기
2. 전화번호 입력
3. 인증번호 문자로 받기
4. 인증번호 입력
5. 이름 입력
6. 프로필 사진 설정 (나중에 해도 돼요!)

완료! 이제 카톡 쓸 수 있어요!

💬 메시지 보내기

👦 윤호
할아버지! 이제 손주한테
메시지 보내는 법 알려드릴게요!

3가지 방법이 있어요:
1. 친구 목록에서 찾기
2. 검색으로 찾기
3. 전화번호로 찾기
👴 할아버지
제일 쉬운 방법으로 알려줘!
👦 윤호
친구 목록이 제일 쉬워요!

1. 카카오톡 열기
2. 아래쪽 "친구" 탭 누르기
3. 손주 이름 찾기
4. 이름 터치!
5. "1:1 채팅" 버튼 누르기
6. 메시지 입력하고 전송! 📤
✍️ 메시지 작성 팁
타이핑이 어려우신가요?

1. 메시지 입력창 옆 마이크 버튼 🎤
2. 말하면 음성 인식으로 입력!
3. "손주야 할아버지야" 말하면
자동으로 글자로 바뀌어요!

노란색 비행기 버튼 누르면 전송!

📷 사진 보내기

📸 손주 사진 공유하기
사진 전송

1. 채팅방 열기
2. 입력창 옆 + 버튼 터치
3. "앨범" 선택
4. 보내고 싶은 사진 선택
5. "전송" 버튼!

여러 장 한번에 보낼 수 있어요!
사진 여러 개 선택하고 전송!
👵 할머니

👨‍👩‍👧‍👦 단체 채팅방

👨‍👩‍👧 가족 단체방 만들기
여러 명과 대화

단체방이 뭐예요?
가족 모두가 함께 대화하는 방!

만드는 방법:
1. 친구 탭에서 "대화" 버튼
2. 초대할 가족 선택
3. "확인" 버튼
4. 단체방 완성!

좋은 점:
• 가족 소식 한번에 공유
• 모임 날짜 정하기
• 손주 사진 모두에게 보내기

아버님! 제가 가족 단체방
만들어드릴게요!
