💻 ChatGPT 시작하기

1️⃣ ChatGPT 접속하기
두 가지 방법

방법 1: 웹사이트
1. 스마트폰에서 네이버 열기
2. "ChatGPT" 검색
3. 첫 번째 링크 클릭
4. "Try ChatGPT" 버튼!

방법 2: 앱 설치
1. 플레이 스토어에서 "ChatGPT" 검색
2. 설치하기
3. 앱 열기

무료로 쓸 수 있어요!
2️⃣ 질문하는 방법
쉬워요!

1. 화면 아래 입력창 찾기
2. 평소에 말하듯이 질문 입력
3. 전송 버튼 누르기
4. 잠시 기다리면 답변 나와요!

예시 질문들:
• "김치찌개 레시피 알려줘"
• "혈압 낮추는 음식"
• "감기 걸렸을 때 먹으면 좋은 것"
• "무릎 통증에 좋은 운동"
