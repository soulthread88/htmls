광케이블식 화재감지시스템

전력구·통신구·공동구 지하구용 P형 복합식 수신기 + 광케이블식 차동식분포형 감지기
// 한눈에 보기

유노시스템의 광케이블식 화재감지시스템은 전력구·통신구·공동구처럼 서지와 노이즈에 쉽게 노출되는 지하구에서 광케이블식 차동식분포형 감지기로 화재를 감시하고 경보하는 시스템입니다. 지하구용 P형 복합식 화재수신기에 광케이블식 검출부(ADS)를 수신기당 최대 2개, 감지선(FOS)을 최대 1.5km까지 연결하며, 관할 소방본부의 통합감시시설과 통제실 통합관제시스템(IMS), 변전소 SCADA(최대 32개 접점)와 연동합니다.

광케이블식 화재감지시스템지하구 화재감지차동식분포형 감지기지하구용 P형 복합식 수신기
// 01 / OVERVIEW

제품 개요

01 / FIBER-OPTIC FIRE DETECTION

광케이블식 화재감지시스템

지하구 구간마다 검출부와 로컬수신기를 두고, 감시제어실의 통합수신기와 광통신으로 연결합니다. 광케이블 자체가 열을 감지하는 센서라 전기 신호를 쓰는 감지기보다 서지·노이즈의 영향을 덜 받습니다.

  • 구간별 로컬수신기(지하구용·전력구용) → 감시제어실 통합수신기로 광통신 연결
  • 발신기·지구경종·방화문·환풍기·소화장치와 연동
  • 무선통신장치로 소방본부 119종합상황실·통합관제시스템(IMS)에 상태 전송
  • 스카다확장장치로 변전소 SCADA에 최대 32개 접점 연동
감지선(FOS) 최대 1.5km수신기당 검출부 최대 2개SCADA 최대 32접점AC 220V · DC 24V
광케이블식 화재감지시스템소방통합감시시설통합관제시스템 IMSSCADA 확장장치
// 02 / CONFIGURATION

시스템 구성도

구성도를 차례로 보시면 전체 흐름을 이해할 수 있습니다. 그림을 누르면 크게 볼 수 있습니다.

① 광케이블식 화재감지시스템 전체 구성

왼쪽과 가운데 아래의 검출부·로컬수신기(지하구용, 전력구용)가 각 구간을 감시하고, 점선으로 표시된 광통신 링으로 감시제어실의 통합수신기와 이어집니다. 통합수신기 옆 무선통신장치가 소방본부 119종합상황실과 통합관제시스템(IMS)으로 정보를 보내고, 오른쪽 아래 스카다확장장치가 변전소 SCADA에 최대 32개 접점을 넘깁니다.

  • 검출부 + 로컬수신기: 구간별 광케이블 감지
  • 감시제어실: 통합수신기 · 무선통신장치
  • 상위 연동: 소방본부 119 · IMS · 변전소 SCADA
광케이블식 감지기 검출부 ADS로컬수신기 지하구감시제어실 통합수신기광케이블식 화재감지시스템 구성도

// 04 / COMPONENTS

구성 요소

01 / COMPONENT

검출부 · 로컬수신기

광케이블 감지선의 온도 변화를 읽는 검출부와, 구간의 경보·상태를 표시하는 로컬수신기입니다. 지하구용과 전력구용이 있습니다.

02 / COMPONENT

감시제어실 통합수신기

모든 구간의 로컬수신기를 묶어 한곳에서 감시하는 통합수신기와, 소방본부·관제센터로 정보를 보내는 무선통신장치입니다.

03 / COMPONENT

변전소 SCADA 연동

스카다확장장치가 화재·고장 신호를 변전소 SCADA 시스템에 최대 32개 접점으로 넘겨 전력 설비 운영과 함께 관리합니다.

// FAQ

자주 묻는 질문

광케이블식 화재감지시스템은 어디에 쓰이나요?

전력구·통신구·공동구처럼 서지와 노이즈에 노출되기 쉬운 지하구에서 화재를 감시하고 경보하는 데 쓰입니다.

감지선은 얼마나 길게 연결할 수 있나요?

광케이블식 감지선(FOS)은 최대 1.5km까지 연결하며, 감지 회로는 500m와 1.5km 두 종류입니다. 수신기 하나에 검출부(ADS)를 최대 2개 연결합니다.

다른 시스템과 어떻게 연동하나요?

무선통신장치로 관할 소방본부 119종합상황실과 통합관제시스템(IMS)에 정보를 보내고, 스카다확장장치로 변전소 SCADA에 최대 32개 접점을 연동합니다.
