SCADA 확장장치

현장 수신기와 중앙 SCADA 시스템 간 통신을 연결하는 확장 장치. 최대 32대의 수신기를 하나의 SCADA 서버에 통합하여 효율적인 중앙 집중 관제를 실현합니다.

🔌
다중 수신기 연결최대 32대 수신기 동시 접속. RS-485 / RS-232 / Ethernet 통신 지원.
⚙️
프로토콜 변환Modbus RTU ↔ TCP/IP 프로토콜 변환. 레거시 장비와 최신 시스템 연동.
💡
저발열 내구 설계DC 24V 저전력 동작. 산업 환경 대응 광범위 온도 범위 (-20~70°C).
항목사양
통신 방식RS-485 / RS-232 / Ethernet (TCP/IP)
접속 수신기 수최대 32대
전원DC 24V
프로토콜Modbus RTU, Modbus TCP, SCADA
동작 온도-20 ~ 70°C

DNC 디지털 노드 컨트롤러

분산된 DTS 감지기 노드들을 네트워크로 통합하는 디지털 노드 컨트롤러. 링 통신 방식으로 이중화 통신 경로를 구성하여 신뢰성을 높입니다.

🔄
링(Ring) 통신 구조이중화 통신 경로 구성. 단선 발생 시 자동 우회하여 통신 유지.
🤝
Peer-to-Peer 통신노드 간 직접 통신 지원. 중앙 서버 부하 최소화.
📱
IoT 연동MQTT, REST API 지원. 클라우드 및 IoT 플랫폼 연결 가능.
