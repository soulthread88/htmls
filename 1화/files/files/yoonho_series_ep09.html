📱 번역 AI 사용하기

1️⃣ 파파고 사용법
네이버 파파고:

📱 파파고 앱 설치
→ 플레이스토어/앱스토어에서 다운

💬 텍스트 번역
→ 한국어 입력하면 영어로 변환

📷 이미지 번역
→ 사진 찍으면 글자 인식해서 번역

🎤 음성 번역
→ 말하면 외국어로 들려줘요
2️⃣ 구글 번역 사용법
구글 번역:

🌐 100개 이상 언어 지원
→ 파파고보다 더 많은 언어!

💬 대화 모드
→ 실시간으로 대화 번역

📝 필기 입력
→ 손으로 쓴 글자도 인식

💾 오프라인 번역
→ 인터넷 없어도 사용 가능
3️⃣ 실생활 활용법
이럴 때 사용하세요:

✈️ 해외여행
→ 레스토랑 메뉴, 표지판 읽기

📧 이메일 작성
→ 외국 친구에게 편지 쓰기

🛍️ 해외 쇼핑
→ 제품 설명서 이해하기

📺 외국 콘텐츠
→ 영화, 드라마 자막 이해
