📱 영상통화 앱 알아보기

1️⃣ 주요 영상통화 앱
쉬운 순서대로:

💬 카카오톡 (제일 쉬워요!)
→ 이미 쓰고 계시면 바로 가능
→ 1:1 통화, 단체 통화 가능
📹 줌(Zoom)
→ 여러 명이 한꺼번에
→ 친구들과 모임할 때 좋아요
📞 페이스타임 (아이폰)
→ 아이폰끼리 통화
📱 구글 미트
→ 구글 계정으로 사용
2️⃣ 카카오톡 영상통화
영상통화 거는 법:

1️⃣ 카카오톡 앱 열기
2️⃣ 통화하고 싶은 친구 채팅방 들어가기
3️⃣ 우측 상단 전화 아이콘 누르기
4️⃣ 영상통화 선택
5️⃣ 상대방이 받으면 얼굴 보여요!
📱 카카오톡 영상통화 화면 예시 (16:9)
3️⃣ 줌(Zoom) 사용하기
줌으로 모임하기:

📱 줌 앱 설치하기
→ 플레이스토어/앱스토어에서
📬 초대 링크 받기
→ 주최자가 보낸 링크 클릭
📹 카메라 켜기
→ 화면 아래 카메라 아이콘
🎤 마이크 켜기
→ 말하기 버튼 누르기
👥 여러 명 동시 통화
→ 모두의 얼굴 한번에!
