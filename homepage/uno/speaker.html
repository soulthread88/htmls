// Transverse Wave Speaker

횡파
스피커

UNO SYSTEM|TRANSVERSE WAVE SPEAKER

진동자와 진동판으로 구성된 새로운 형식의 초저전력 스피커입니다. 공기를 앞뒤로 밀어내는 종파(Longitudinal) 방식과 달리, 진동판이 좌·우 또는 상·하로 흔들리며 공기를 횡파(Transverse) 형태로 전달해 거리에 따른 감쇠가 적고 Echo가 없어 소음 환경에서도 뚜렷한 음성 전달이 가능합니다.

주요 특징

음 전달 효율 높음
횡파 방식으로 감쇠율이 낮아 먼 거리에서도 음압을 유지합니다. 도달 거리 최대 100m로 넓은 공간을 커버합니다.
🖼
이미지/영상

Echo 없음
반향음 없이 명확한 음성을 전달합니다. 지하철·터널 등 반사가 심한 소음 환경에서 특히 효과적입니다.
🖼
이미지/영상

무지향성
방향에 구애받지 않는 균일한 음 전달로, 넓은 공간이나 다수 청취 지점에도 고르게 적용할 수 있습니다.
🖼
이미지/영상

// System Configuration

시스템 구성

STEP 01
🔊
일반 스피커 (종파)
공기를 앞뒤로 밀어내는 종파(Longitudinal Wave) 방식입니다. 파동 간섭이 크고 거리에 따른 감쇠율이 높아 소음 환경에서 명료도가 떨어집니다.
  • 공기를 앞뒤로 압축·팽창
  • 파동 간섭이 큼
  • 거리 감쇠율 높음
  • 반향(Echo) 발생
+
클릭하여
이미지 삽입
STEP 02
📡
횡파 스피커 (횡파)
진동판이 옆으로 흔들리며 공기 입자를 움직이는 횡파(Transverse Wave) 방식입니다. 간섭이 적고 감쇠율이 낮아 먼 거리까지 또렷하게 전달됩니다. 방울벌레·종(鐘) 소리가 대표적 횡파 음원입니다.
  • 진동판 좌·우 / 상·하 진동
  • 파동 간섭이 적음
  • 거리 감쇠율 낮음
  • Echo 없음 (무반향)
  • 방울벌레·종소리와 유사한 음원
+
클릭하여
이미지 삽입
STEP 03
📋
특허 기반 구조
등록특허 KR10-1273442(2013.06.04)에 기반한 진동자+진동판 초저전력 구조입니다. 하우징 상·하부 측면에서 진동판이 굽혀지도록 체결하고 고무 사각 테두리로 고정합니다.
  • 특허권자 유노시스템㈜ / 발명자 차주헌
  • 출원 2011.12.01 · 공고 2013.06.11
  • IPC H04R 7/02 · H04R 1/20
  • 보강판으로 기판 외측 보호 · 무반향

// Application Cases

응용 사례

🚉
공공장소 안내 방송
낮은 감쇠율로 원거리 전달이 뛰어나고 벽면 반사 울림이 없어, 소음이 많은 역사·터미널·공항에서도 안내 음성이 또렷합니다.
🎤
휴대용 기기
전력 소모가 극히 낮아 배터리 기기에 최적입니다. 연속 15시간 사용, 950g 경량 설계로 이동용 확성 장치에 적합합니다.
🎓
조용한 공간의 방송
Echo가 없어 선명도가 높고 음절이 명확합니다. 강당·교실·어학실에서 음성이 고르게 퍼져 청취 피로를 줄입니다.
📺
박형 설치 기기
두께 42mm 슬림 구조로 별도 배관 공사 없이 기존 디스플레이·사이니지에 바로 통합할 수 있습니다.
