// Features

주요 특징

📡
블랙박스 데이터 집중
현장 내 다수의 스마트 건설 블랙박스로부터 GPS 위치, 충격 감지, 영상 데이터를 수집·집중하여 관제 서버로 안정적으로 전달합니다.
🔗
통신 음영 구역 해소
건물 사이, 지하, 굴착 현장 등 LTE 신호가 약한 구역에 배치하여 블랙박스가 항상 관제 서버와 연결될 수 있도록 통신 커버리지를 확장합니다.
🌐
이중 통신 경로
LTE 주 통신과 Wi-Fi 부 통신을 이중으로 운용하여 통신 장애 시 자동 절체합니다. 데이터 손실 없는 안정적인 중계를 보장합니다.
🛡️
옥외 설치 대응 설계
IP65 이상 방수·방진, 폭넓은 동작 온도(-20 ~ 60 °C)로 건설 현장의 혹독한 환경을 견딥니다. 폴 마운트·벽면 설치가 모두 가능합니다.
⚡
PoE / 태양광 전원
PoE(Power over Ethernet) 또는 태양광 패널로 전원을 공급할 수 있어 전원 인프라가 없는 현장에도 유연하게 설치합니다.
📊
원격 관리
현장 방문 없이 원격으로 베이스스테이션 상태를 모니터링하고 설정을 변경합니다. 장애 발생 시 즉시 알림을 관제 서버에 전송합니다.

// 한눈에 보기

건설 현장 베이스 스테이션(기준국)은 현장 내 다수의 스마트 건설 블랙박스로부터 GPS 위치·충격·영상 데이터를 모아 GIS 관제 서버로 중계하는 현장 기지국입니다. LTE(Cat.4 이상) 주 통신과 Wi-Fi 부 통신을 이중으로 운용해 장애 시 자동 절체하며, IP65 이상 방수·방진, -20~60°C 동작, PoE·DC 12V·태양광 전원, 폴·벽면 설치를 지원합니다.

// FAQ

자주 묻는 질문

통신 장애 시에는 어떻게 되나요?

LTE 주 통신과 Wi-Fi 부 통신을 이중으로 운용해 장애가 나면 자동으로 절체하므로 데이터 손실 없이 중계합니다.

전원이 없는 현장에도 설치할 수 있나요?

PoE 또는 태양광 패널로 전원을 공급할 수 있어 전원 인프라가 없는 현장에도 설치할 수 있습니다.

동시에 몇 대의 블랙박스를 연결할 수 있나요?

블랙박스 최대 수백 대가 동시에 접속하며, 베이스스테이션이 데이터를 집중·중계해 GIS 관제 서버로 전송합니다.

설치 방식과 사용 환경은 어떻게 되나요?

폴 마운트와 벽면 설치가 모두 가능하며, IP65 이상 방수·방진과 -20~60°C 동작 온도로 건설 현장의 옥외 환경을 견딥니다.

현장에 가지 않고도 원격으로 관리할 수 있나요?

OTA 업데이트와 원격 모니터링을 지원하며, 장애가 발생하면 관제 서버로 즉시 알림을 전송합니다.
