✍️ 텍스트 번역

👦 윤호
할머니! 제일 기본적인
텍스트 번역부터 해볼까요?

3가지 방법:
1. 직접 타이핑하기
2. 복사해서 붙여넣기
3. 음성으로 말하기
📝 텍스트 번역 사용법
단계별 따라하기:

1단계: 파파고 앱 열기

2단계: 언어 선택
→ 위쪽: 번역할 언어 (한국어)
→ 아래쪽: 번역될 언어 (영어)
→ 화살표 버튼으로 바꿀 수 있어요!

3단계: 입력창에 번역할 문장 입력
→ 예: "화장실이 어디예요?"

4단계: 자동으로 번역 완료!
→ "Where is the bathroom?"

음성 듣기: 스피커 버튼 누르면
AI가 발음해줘요!

📸 사진 번역

📷 메뉴판, 간판 번역하기
사진만 찍으면 끝!

사용 방법:

1. 파파고 앱에서 카메라 아이콘 터치
2. 메뉴판이나 간판에 카메라 대기
3. 사진 찍기 또는 앨범에서 선택
4. 번역하고 싶은 부분 터치
5. 자동으로 번역!

활용 예시:
• 식당 메뉴판 번역
• 공항 안내판 읽기
• 관광지 설명문 이해
• 상품 설명서 읽기

🎤 음성 번역 (대화)

💬 실시간 통역
말하면 바로 번역!

사용 방법:

1. 파파고에서 대화 아이콘 터치
2. 언어 설정 (한국어 ↔ 영어)
3. 마이크 버튼 누르고 말하기
4. AI가 음성으로 번역해줘요!

실전 예시:
→ 할머니: "이것 얼마예요?"
→ 파파고: "How much is this?"
→ 상대방 대답도 듣고 번역!

여행, 쇼핑할 때
정말 유용해요!
